# University of Sahiwal - Demo Website

A responsive informational website for the University of Sahiwal built with Vite and Tailwind CSS v4.

## Features

- Responsive design (mobile, tablet, desktop)
- Scroll-triggered animations (fade-up, fade-left, fade-right, stagger)
- Event gallery with hover-expand cards
- Department overview with program listings
- Vice Chancellor's message section
- Latest news cards with clickable cards
- Footer with contact info and social links

## Tech Stack

- **Vite** — Build tool
- **Tailwind CSS v4** — Utility-first CSS framework
- **Vanilla JS** — Intersection Observer for scroll animations
- **Google Fonts** — EB Garamond & Sora

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
